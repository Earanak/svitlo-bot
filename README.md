# Svitlo Bot

Личный Telegram-бот: график отключений ДТЕК Одеські електромережі для одного адреса.

- предупреждение за 60 и за 30 минут до отключения + когда включат;
- сообщение, когда ДТЕК публикует или меняет график;
- аварийное отключение по адресу: когда началось и когда обещают включить, изменение времени;
- объявления ДТЕК об экстренных отключениях;
- закреплённое сообщение со статусом (обновляется каждые ~10 минут);
- напиши боту что угодно — пришлёт свежий статус при следующей проверке (до ~10 минут).

## Настройки (Settings → Secrets and variables → Actions)

Secrets:
- `TG_TOKEN` — токен бота от @BotFather
- `ADDRESS` — `м. Одеса|Фонтанська дорога|16/2`
- `TG_CHAT_ID` — необязательно

Variables:
- `GROUP` — твоя группа из бота ДТЕК, например `3.1`. Если задана, бот использует её, а не группу с сайта, и предупредит, если сайт показывает другую.

Адрес и токен скрыты, код и `state.json` публичны.
